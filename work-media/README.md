# Work page recordings

Screen recordings of the ten portfolio sites for the /work/ page: a 25 s slow scroll of each
homepage on desktop (1440×900 viewport, encoded at 1280 wide) and phone (390×844, encoded at
540 wide), H.264, no audio, plus a poster frame for each. Staging pulls these into
`wp-content/uploads/work/` and the `_banks_work` meta of each Work project points at them there.

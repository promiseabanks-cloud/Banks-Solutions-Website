# API

A defined way for two pieces of software to exchange information automatically, without anyone copying and pasting.

## Why it matters

This is what makes your website, CRM, accounting system and payment provider behave as one system rather than four. When someone says two tools "integrate", they usually mean one has an API the other can use. If a tool you rely on has no API, expect to keep entering things twice.

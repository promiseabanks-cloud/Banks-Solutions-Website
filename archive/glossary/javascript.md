# JavaScript

The programming language that makes web pages interactive: menus, sliders, forms that respond as you type.

## Why it matters

Worth knowing because too much of it is a common cause of slow sites, and because content that only appears after JavaScript runs can sometimes be missed by search engines and AI crawlers. Important information should be present in the page itself, not assembled afterwards.
